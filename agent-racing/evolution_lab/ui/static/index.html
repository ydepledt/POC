UN LABORATOIRE À VOTRE MESURE
Des limites explicites.
Les ressources de votre machine restent sous contrôle.
Budgets des prochains traitements
Une seule tâche est traitée à la fois. Les budgets disque sont vérifiés avant les lancements ; la mémoire et la durée sont surveillées pendant le calcul. La dernière sauvegarde est conservée si un budget est dépassé.
Vos archives sont conservées. Aucun nettoyage automatique n’est activé. Lorsque le budget disque est atteint, les nouveaux calculs sont bloqués. Vous pouvez exporter vos résultats et gérer les archives dans le dossier local.
