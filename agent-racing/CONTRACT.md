# Evolution Lab integration contract

Python package `evolution_lab`. Root owns CLI, installation, integration tests and documentation. Engine agent owns `evolution_lab/core/`, `evolution_lab/training.py`, `evolution_lab/config.py`, and engine tests. Video agent owns `evolution_lab/rendering/`, `evolution_lab/video/` and video tests. UI agent owns `evolution_lab/ui/`, `evolution_lab/automation/`, `evolution_lab/publishing/` and UI/automation tests. Do not edit another owner's files without agreement.

Public engine API: `from evolution_lab.config import SimulationConfig`; dataclass with population=1500, generations=30, seed=42, track='oval', difficulty='easy', max_seconds=40.0 (per generation), budget_seconds=600.0, mutation_rate=0.15, mutation_strength=0.25, elite_fraction=0.05, sensors=7, video_duration=24.0. Additional fields allowed with defaults. `from evolution_lab.training import train`; `train(config: SimulationConfig, run_dir: Path, resume: bool=False, stop_requested: Callable[[], bool] | None=None) -> dict`. Must use atomic writes and checkpoint at generation boundaries. `stop_requested` is optional.

Artifacts within run_dir: config.json, track.json, metrics.json (JSON list of per-generation dicts), summary.json, checkpoint.npz, best_brain.npz, replays/gen_0001.npz etc. Train writes status.json atomically while running; keys status, generation, best_score, best_progress, elapsed_seconds, message. Generation is ONE based. Metrics keys generation, population, alive, mean_score, best_score, max_progress (0..1), max_distance, checkpoint_counts (list), completed, elapsed_seconds, generation_seconds, steps_per_second. Additional keys allowed. Summary includes status, population, generations, best_progress, best_score, completed, elapsed_seconds, seed. Replay selection must retain first and representative record generations plus final, without retaining entire training history in RAM.

track.json: name, width (full road width, world units), closed (boolean), centerline (list of [x,y]), length, checkpoints (list of [x,y]); optional extra keys. All replay geometry uses these world coordinates. Replays NPZ: positions float32 [T,N,2], headings float32 [T,N] radians, alive bool [T,N], progress float32 [T,N] fractions, times float32 [T], scores float32 [T,N], generation scalar, completed bool [T,N] optional. A replay contains exactly one generation and actual simulated state. No rendering during training.

Public video API: `from evolution_lab.video import export_video`; `export_video(run_dir: Path, output_path: Path | None=None, duration: float=24.0, fps: int=30, width: int=1080, height: int=1920) -> dict`. Default output run_dir/video.mp4. Creates thumbnail.png, video_metadata.json (including validation), publication.json (title description hashtags and draft state). Use imageio_ffmpeg.get_ffmpeg_exe() for packaged FFmpeg if system binary unavailable. Renderer may use Pillow. Never fabricate claims; captions use metrics. CLI root supports `train --config PATH --run-dir PATH [--resume]`, `render --run-dir PATH [--duration N]`, `run --config PATH --run-dir PATH` (both), `serve --port 8765`, `benchmark`, `validate`.

UI is local FastAPI + static HTML/CSS/JS, binds 127.0.0.1 by default. Entrypoint `evolution_lab.ui.server:create_app(data_dir: Path | None=None)` returns FastAPI app. Jobs run subprocess `sys.executable -m evolution_lab run --config ... --run-dir ...` from project root. Stop by creating run_dir/STOP; root CLI passes a stop callback. Automation SQLite queue, restart recovery, disabled default scheduler. Local interface is French. Publication requires external API credentials and explicit consent; expose honest blocked/manual export state, no fake integrations. Scheduler does not publish. Root requirements will provide numpy, scipy, numba, Pillow, imageio-ffmpeg, fastapi, uvicorn, psutil, pytest, httpx, shapely.
